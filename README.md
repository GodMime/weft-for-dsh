# weft-for-dsh

面向 dsh 的多 Agent 编排插件，目标是在 dsh 中组织需求、工作流和多个编码 Agent 的协作。

项目目前处于设计与原型验证阶段，尚未发布可安装的产品版本。正式源码将随实现逐步加入本仓库。
